## Quick Deploy (5 Steps, ~10 minutes)

### 1. Install Dependencies

```bash
# Backend
cd document-service && npm install @nestjs/schedule

# Frontend
cd gravity-business-apps && npm install date-fns
```

### 2. Run Migrations

```bash
cd document-service && npm run migration:run
```

### 3. Build Backend

```bash
cd document-service && npm run build
```

### 4. Build Frontend

```bash
cd gravity-business-apps && npm run build
```

### 5. Deploy

```bash
# Backend: npm run start:prod
# Frontend: Deploy dist/ folder
```
