# Cursor Rules Auto-Update via Bitbucket Pipelines

## ✅ Current Setup

Automated dependency updates for `@newwork/cursor-rules` using **Bitbucket Pipelines scheduled builds**.

---

## 🎯 How It Works

### Automatic Updates (Scheduled)

**Every Monday at 9 AM UTC:**

1. **Pipeline checks** for new `@newwork/cursor-rules` version
2. **If update available**:
   - Creates new branch: `chore/update-cursor-rules-{version}`
   - Updates `package.json` and `package-lock.json`
   - Syncs cursor rules via `postinstall`
   - Commits changes
   - Pushes branch
   - Creates Pull Request automatically
3. **PR triggers validation**:
   - Install dependencies
   - Build screens
   - Run SonarQube scan
4. **You review and merge** when pipeline passes

**Timeline**: PR created and validated within 15-20 minutes

---

### Manual Check (On-Demand)

You can also check for updates manually anytime:

**Bitbucket UI**:

1. Go to **Pipelines** → **Run pipeline**
2. Select **Custom**: `check-cursor-rules-update`
3. Click **Run**

**Result**: Same as scheduled - creates PR if update available

## 📋 Configuration

### Scheduled Pipeline

**File**: `bitbucket-pipelines.yml`

```yaml
schedules:
  - cron: '0 9 * * 1' # Every Monday at 9 AM UTC
    branches:
      develop:
        - step:
            name: Check cursor-rules updates
            script:
              - bash scripts/check-cursor-rules-update.sh
```

### Update Script

**File**: `scripts/check-cursor-rules-update.sh`

**What it does**:

1. ✅ Gets current version from `package.json`
2. ✅ Gets latest version from npm registry
3. ✅ Compares versions
4. ✅ Skips if already up-to-date
5. ✅ **Skips major updates** (requires manual review)
6. ✅ Creates branch for minor/patch updates
7. ✅ Updates package and syncs rules
8. ✅ Commits and pushes
9. ✅ Creates PR via Bitbucket API

## 🔒 Safety Features

### 1. Major Version Protection

**Major updates (v1.x → v2.x) are skipped automatically**

```bash
if [ "$CURRENT_MAJOR" != "$LATEST_MAJOR" ]; then
  echo "⚠️  Major version change - manual review required"
  exit 0
fi
```

**Why**: Breaking changes need human review

**Action**: Update manually when ready

### 2. PR Validation

Every auto-generated PR runs through:

- ✅ Hash file change check
- ✅ Dependency installation
- ✅ Screen builds
- ✅ SonarQube scan

**Only merge if all pass!**

### 3. Clean Git History

Commits follow conventional commits:

```
chore(deps): update @newwork/cursor-rules to 1.5.0

- Updated from 1.4.0 to 1.5.0
- Synced cursor rules via postinstall
- Rules validated successfully

Auto-generated by scheduled pipeline
```

## 🔧 Configuration Options

### Change Schedule

Edit `bitbucket-pipelines.yml`:

```yaml
# Daily at 9 AM
cron: '0 9 * * *'

# Every Monday and Thursday
cron: '0 9 * * 1,4'

# First day of month
cron: '0 9 1 * *'
```

### Change Target Branch

Edit `scripts/check-cursor-rules-update.sh`:

```bash
# Change destination branch for PR
"destination": {
  "branch": {
    "name": "main"  # Instead of "develop"
  }
}
```

### Enable Auto-Merge

To auto-merge PRs (not recommended):

1. Add to script before creating PR:

```bash
# Add reviewers and auto-approve
"reviewers": [],
"close_source_branch": true
```

2. Configure Bitbucket branch permissions:
   - Settings → Branch permissions
   - Enable "Auto-merge when all checks pass"

**⚠️ Warning**: Only do this if you trust the automation completely!

## 🐛 Troubleshooting

### Pipeline Not Running

**Check 1**: Is schedule enabled?

- Pipelines → Schedules → Verify enabled

**Check 2**: Correct branch?

- Schedule runs on `develop` branch only

**Check 3**: Check logs

- Pipelines → Schedules → View execution history

### Branch Pushed But No PR?

**This is normal!** The script pushes the branch, then you create the PR manually:

1. Go to Bitbucket
2. You'll see notification: "Branch chore/update-cursor-rules-x.x.x was pushed"
3. Click "Create pull request"
4. Fill in details (or use suggested title/description from pipeline logs)
5. Create PR
6. Pipeline validates automatically

### Script Fails

**Check 1**: Permissions

```bash
chmod +x scripts/check-cursor-rules-update.sh
```

**Check 2**: Dependencies

- Script requires: `curl`, `jq`, `git`
- Pipeline installs these automatically

**Check 3**: npm credentials

- Ensure `NEWWORK_NMP_CREDENTIALS` is set
