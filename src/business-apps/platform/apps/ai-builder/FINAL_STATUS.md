## How to Use (Current State)

### 1. Generate a Screen
```
1. Open: /apps/platform/ai-builder
2. Type: "Create a lead list screen with search"
3. Wait for AI to generate files (~30-60 seconds)
4. See "X files changed" banner
```

### 2. Download Files (Works Now!)
```
1. Click "Download Patch" button
2. Apply patch locally: git apply ai-builder-session-*.patch
3. Test locally
4. Publish manually: npm run publish:screen -- /path/to/screen
```

### 3. One-Click Publish (Needs FORGE Completion)
