# Approved Dependencies

## Allowed Libraries
- UI: `react`, `tailwind v4`, `nw-design-system`, `@dnd-kit`
- State: `zustand`
- DOM: `react-dom`
- Language: `typescript`
- Date/Time: `dayjs` (with `weekday` and `localeData` plugins)
- Tooling: `prettier`, `eslint`
- Charts: `recharts`

## Restrictions
- Do not add UI themes or icon libraries without approval
- Reuse existing packages whenever possible
