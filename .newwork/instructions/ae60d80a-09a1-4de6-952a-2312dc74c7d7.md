# NEWWORK App Builder: Analysis Request

## 📋 What the User Wants to Build

**Feature Name:** IRM investments
**Module:** crm
**Build Mode:** Extend Existing App
**Existing App:** Not specified - AI to determine best location

**Description:**
The IRM Investments feature is designed to enable users to manage and track investment activities within the CRM platform effectively. It will allow users to create, update, and monitor investment portfolios, linking directly to CRM contacts and profiles for seamless integration. This feature will support various investment types and integrate with real-time market data to provide up-to-date portfolio valuations. Additionally, it will offer analytical tools to assess investment performance and risks, tailored to the needs of both novice and experienced investors.


**✨ Acceptance Criteria:**
- The feature must integrate seamlessly with existing CRM contacts and profiles.
- Users should be able to create, update, and delete investment entries.
- The system must provide real-time valuation of the investments based on current market data.
- It should include tools for performance analysis and risk assessment.
- The feature must support various investment types, including stocks, bonds, and mutual funds.
- All data must be encrypted in transit and at rest.
- The feature must be accessible from both the desktop and mobile versions of the platform.


**✨ Expected Behavior:**
When a user accesses the IRM Investments feature, they should be able to view a dashboard summarizing their current investment portfolio, including recent performance metrics. Users can add a new investment by selecting the 'Add Investment' button, which prompts them to fill out details such as investment type, amount, and linked contact from CRM. The system should update investment values in real-time, reflecting current market conditions. Users should receive notifications for significant performance changes or risks identified by the system. Edge cases include handling incorrect market data input, ensuring the system maintains performance during high volatility, and verifying user permissions for investment data access.


**✨ Technical Notes:**
Implementation will require APIs for real-time financial market data, which may involve subscription costs or usage limits. Integration with existing CRM data structures must be planned carefully to maintain data integrity and security. The feature's responsiveness and accuracy in real-time data handling are critical, requiring robust backend architecture and possibly the use of web sockets for live updates. Encryption standards such as AES for data at rest and TLS for data in transit should be enforced. The development team must also consider the mobile responsiveness and consistent user experience across devices.

```
├── {AppName}.tsx
├── hooks/
│   └── use{Feature}.ts
├── queries/
│   └── {Feature}Queries.ts
└── components/
    └── {ComponentName}.tsx
```

### Data Types
- Primary keys: `uuid` (NOT int)
- Foreign keys: `uuid`
- Timestamps: `timestamptz`
- Created/Updated by: `uuid` (references user)

### GraphQL Hooks Pattern
```typescript
export const useEntities = (context: BusinessAppContextProps) => {
  const client = useGraphqlClient(context.accessToken);
  return useQuery({
    queryKey: ["entities", context.companyId],
    queryFn: async () => {
      const query = `...`;
      return await client.request(query, { companyId: context.companyId });
    },
    enabled: !!context.accessToken
  });
};
```
